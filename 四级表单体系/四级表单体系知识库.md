# 城发投四级表单体系知识库

## 一、四级表单体系概述

**定义**：四级表单体系是城发投资为实现业财融合和精细化管理而建立的一套分层级、分维度、分角色的财务数据管理工具。

**核心理念**：以业务为出发点，以信息化思维优化业财数据体系，支撑管理决策。

**核心原则**：
- 业务台账要支撑业务决策（现金流平衡）
- 财务系统数据要支撑财务决策（杜邦分析、经济增加值）
- 业财决策（管理决策）由业务和财务数据共同支撑（口袋毛利率、回款率）

**关键协同规则**：
- 数据传递：四级表→三级表（每日21:00自动同步）；三级表→二级表（勾选上报指标）；二级表→一级表（月关键指标穿透）
- 风控联动：政府评价表得分<90→回款申请表金额自动扣减；刚兑还款超期→一级表自动标红
- 操作约束：四级表需上传合同/回单等扫描件，无附件则三级表标黄预警

## 二、四级表单体系架构

### 2.1 表单层级结构

| 层级 | 使用者 | 核心功能 | 表单性质 |
|------|--------|----------|----------|
| **一级表** | 总经理/副总经理 | 战略目标监控与经营决策 | 综合管理工具 |
| **二级表** | 部门主任 | 部门考核与数据分析 | 职能管理工具 |
| **三级表** | 业务主管 | 多维度业务数据汇总 | 业务管理工具（手工或系统） |
| **四级表** | 经办人（业务/财务岗位） | 原始台账录入与流程执行 | 单据汇总工具（手工或系统） |

### 2.2 表单设计维度

表单设计关注的关键指标：
- 投资回报率
- 资金折现率
- 违约金
- 罚息

## 三、一级表单体系（管理层决策工具）

一级表单是管理层（各级总经理、副总经理）使用的综合管理工具，结合公司目标责任书、经营分析设计指标。

## 七、核心业务场景与流程

### 7.1 回款闭环流程

```
合同签订 → 收入确认 → 回款申请至区县政府 → 政府审批流程 → 回款到账 → 刚兑还款
```

**四级表单协同节点**：
- 政府审批：在"回款申请信息表"中关联"政府评价信息表"得分
- 回款核验："回款回单信息表"需与"回款申请信息表"金额、付款单位交叉核对

### 7.2 股东借款流程

```
发起借款请示 → 董事会决议 → 签订借款协议 → 业财填借款信息表
```

## 九、实施路径与方法论

### 9.1 实施阶段

**阶段一：基础搭建（0-1个月）**
- 建立四级表单框架
- 配置表单字段和关联关系
