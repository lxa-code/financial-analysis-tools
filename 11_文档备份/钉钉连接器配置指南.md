# 钉钉连接器配置指南

## 一、创建钉钉群机器人

### 步骤1：创建或打开钉钉群
- 打开钉钉桌面端或手机端
- 创建新群（或使用已有群聊）

### 步骤2：添加机器人
1. 点击群设置（右上角「···」或群头像）
2. 选择「智能群助手」
3. 点击「添加机器人」
4. 选择「自定义机器人」
5. 设置机器人名称（如：WorkBuddy通知）

### 步骤3：获取Webhook地址
- 复制生成的Webhook地址，格式类似：
  ```
  https://oapi.dingtalk.com/robot/send?access_token=XXXXXXXXXXXXXX
  ```
- **重要**：妥善保管此链接，不要泄露给他人

### 步骤4：设置安全策略（可选）
- 加签验证（推荐）：复制加签密钥
- IP白名单：如需限制访问来源

## 二、WorkBuddy钉钉连接器JSON配置

### 基础配置（文本消息）

```json
{
  "name": "钉钉机器人推送",
  "description": "通过钉钉机器人发送消息通知",
  "endpoint": "https://oapi.dingtalk.com/robot/send?access_token=你的TOKEN",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json"
  },
  "body": {
    "msgtype": "text",
    "text": {
      "content": "${message}"
    }
  },
  "parameters": {
    "message": {
      "type": "string",
      "required": true,
      "description": "要发送的消息内容"
    }
  }
}
```

### 进阶配置（Markdown消息）

```json
{
  "name": "钉钉Markdown推送",
  "description": "支持Markdown格式的钉钉消息",
  "endpoint": "https://oapi.dingtalk.com/robot/send?access_token=你的TOKEN",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json"
  },
  "body": {
    "msgtype": "markdown",
    "markdown": {
      "title": "${title}",
      "text": "${content}"
    }
  },
  "parameters": {
    "title": {
      "type": "string",
      "required": true,
      "description": "消息标题"
    },
    "content": {
      "type": "string",
      "required": true,
      "description": "Markdown格式的消息内容"
    }
  }
}
```

### 带加签验证的配置

```json
{
  "name": "钉钉机器人推送(加签)",
  "description": "使用加签验证的钉钉消息推送",
  "endpoint": "https://oapi.dingtalk.com/robot/send?access_token=你的TOKEN",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json",
    "timestamp": "${timestamp}",
    "sign": "${sign}"
  },
  "body": {
    "msgtype": "text",
    "text": {
      "content": "${message}"
    }
  },
  "parameters": {
    "message": {
      "type": "string",
      "required": true,
      "description": "要发送的消息内容"
    },
    "timestamp": {
      "type": "string",
      "required": false,
      "description": "时间戳（毫秒）"
    },
    "sign": {
      "type": "string",
      "required": false,
      "description": "加签字符串"
    }
  },
  "sign_secret": "你的加签密钥"
}
```

## 三、钉钉消息类型支持

### 1. 文本消息（text）
```json
{
  "msgtype": "text",
  "text": {
    "content": "这是一条测试消息"
  },
  "at": {
    "atMobiles": ["13800138000"],
    "isAtAll": false
  }
}
```

### 2. Markdown消息（markdown）
```json
{
  "msgtype": "markdown",
  "markdown": {
    "title": "日报摘要",
    "text": "### 今日销售日报\n\n- 销售额：¥125,000\n- 同比增长：+15%\n- > 恭喜团队再创佳绩！"
  }
}
```

### 3. 链接消息（link）
```json
{
  "msgtype": "link",
  "link": {
    "title": "销售报表",
    "text": "点击查看详细报表",
    "picUrl": "",
    "messageUrl": "https://example.com/report"
  }
}
```

### 4. 卡片消息（actionCard）
```json
{
  "msgtype": "actionCard",
  "actionCard": {
    "title": "任务通知",
    "text": "您有一个新任务待处理",
    "btnOrientation": "0",
    "singleTitle": "立即处理",
    "singleURL": "https://example.com/task"
  }
}
```

## 四、在WorkBuddy中配置连接器

### 步骤1：打开连接器配置
1. WorkBuddy左侧导航 → **连接器**
2. 右上角点击 **+ 添加连接器**
3. 选择 **自定义连接器**

### 步骤2：粘贴配置
1. 复制上方适合的配置模板
2. 替换 `你的TOKEN` 为实际的access_token
3. 如使用加签，替换 `你的加签密钥`
4. 粘贴到配置编辑框

### 步骤3：测试连接
1. 点击 **测试** 按钮
2. 输入测试参数（如message）
3. 查看返回结果

### 步骤4：保存并使用
1. 配置无误后点击 **保存**
2. 即可在工作流中调用此连接器

## 五、常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 消息发送失败 | access_token过期或错误 | 检查并重新获取Webhook |
| 加签验证失败 | 密钥不匹配 | 确认加签密钥正确 |
| 消息格式错误 | JSON格式不规范 | 检查JSON语法 |
| 被限流 | 发送频率过高 | 钉钉限制每分钟20条 |
