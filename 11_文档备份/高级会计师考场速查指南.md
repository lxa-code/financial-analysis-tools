## 二、教材章节知识体系（含页码索引）

### 第一章 企业战略与财务战略

**核心知识点**：
- SWOT分析：优势、劣势、机会、威胁
- PEST分析：政治、经济、社会、技术
- 总体战略类型：成长型、稳定型、收缩型
- 业务单位战略：成本领先、差异化、集中化
- 财务战略：扩张型、稳健型、防御型

**常用公式**：
```
销售增长率 =（本年营业收入-上年营业收入）/ 上年营业收入 × 100%
总资产增长率 =（期末总资产-期初总资产）/ 期初总资产 × 100%
净资产收益率（ROE）= 净利润 / 平均净资产 × 100%
```

---

### 第二章 企业全面预算管理

**核心知识点**：
- 全面预算的编制方法：固定预算、弹性预算、滚动预算、零基预算
- 预算执行与控制
- 预算考核与评价

**常用公式**：
```
弹性预算公式：
变动成本 = 单位变动成本 × 预计业务量
固定成本 = 固定成本总额（不随业务量变化）

预算执行差异 = 实际数 - 预算数
预算执行差异率 = 差异额 / 预算数 × 100%
```

### 第三章 企业风险管理与内部控制

**核心知识点**：
- COSO内部控制框架五要素
- 风险识别、评估、应对
- 内部控制缺陷认定
- 风险管理策略：规避、降低、分担、承受

**答题要点**：
- 内控缺陷分为：重大缺陷、重要缺陷、一般缺陷
- 风险应对策略需结合具体案例分析

### 第四章 企业投资、融资决策与集团资金管理

**核心知识点（最重要章节之一）**：

**投资决策**：
```
净现值（NPV）= ∑(第t年净现金流量 / (1+折现率)^t) - 初始投资
内含报酬率（IRR）：使NPV=0的折现率
投资回收期 = 原始投资额 / 每年净现金流量（简化计算）
会计收益率 = 年平均净利润 / 平均投资额 × 100%
```

**融资决策**：
```
资本成本计算：
债务资本成本 = 利率 × (1 - 所得税税率)
股权资本成本（CAPM）= 无风险利率 + β × (市场收益率 - 无风险利率)
加权平均资本成本（WACC）= ∑(各种资本占比 × 个别资本成本)

经营杠杆系数（DOL）= 边际贡献 / 息税前利润（EBIT）
财务杠杆系数（DFL）= EBIT / (EBIT - 利息)
总杠杆系数（DTL）= DOL × DFL
```

**集团资金管理**：
- 资金集中管理模式：统收统支、拨付备用金、结算中心、财务公司
- 内部转移定价方法：市场价格法、协商价格法、成本加成法、双重价格法

---

### 第五章 企业成本管理

**核心知识点**：

**本量利分析（CVP）**：
```
保本点销售量 = 固定成本 / (单价 - 单位变动成本)
保本点销售额 = 保本点销售量 × 单价
安全边际 = 实际销售量 - 保本点销售量
安全边际率 = 安全边际 / 实际销售量 × 100%
边际贡献 = 销售收入 - 变动成本
单位边际贡献 = 单价 - 单位变动成本
边际贡献率 = 边际贡献 / 销售收入 × 100%
```

**标准成本法**：
```
成本差异 = 实际成本 - 标准成本
直接材料成本差异 = 数量差异 + 价格差异
直接人工成本差异 = 效率差异 + 工资率差异
变动制造费用差异 = 效率差异 + 耗费差异
固定制造费用差异 = 预算差异 + 能量差异
```

**作业成本法（ABC）**：
```
某产品应分配的作业成本 = 该产品消耗的作业量 × 该作业的单位成本
```

**目标成本法**：
```
目标成本 = 预计销售价格 - 目标利润
成本缺口 = 当前成本 - 目标成本
```

### 第六章 企业并购

**核心知识点**：

**并购价值评估**：
```
目标企业价值评估方法：
1. 资产价值评估法：账面价值、重置成本、清算价值
2. 收益法：NPV法、市盈率法（目标企业价值 = 净利润 × 市盈率）
3. 市场比较法：EV/EBITDA、P/B等
```

**并购支付方式**：
- 现金支付、股票支付、混合支付
- 杠杆收购（LBO）

**并购后整合**：
- 战略整合、组织整合、人力资源整合、文化整合

---

### 第七章 企业绩效评价

**核心知识点**：

**财务指标**：
```
净资产收益率（ROE）= 净利润 / 平均净资产 × 100%
总资产报酬率（ROA）= EBIT / 平均总资产 × 100%
销售净利率 = 净利润 / 销售收入 × 100%
成本费用利润率 = 利润总额 / 成本费用总额 × 100%
```

**EVA（经济增加值）**：
```
EVA = 税后净营业利润 - 资本占用 × 加权平均资本成本
调整后资本 = 平均所有者权益 + 平均带息负债 - 平均在建工程
```

**平衡计分卡（BSC）四个维度**：
- 财务维度、客户维度、内部流程维度、学习与成长维度

```
资产利用率 = 实际使用资产 / 总资产 × 100%
```

## 三、答题万能公式汇总

### 3.1 财务分析类公式

```
流动比率 = 流动资产 / 流动负债
速动比率 =（流动资产 - 存货）/ 流动负债
现金比率 =（货币资金 + 交易性金融资产）/ 流动负债
资产负债率 = 负债总额 / 资产总额 × 100%
已获利息倍数 = EBIT / 利息费用

应收账款周转率 = 营业收入 / 平均应收账款
存货周转率 = 营业成本 / 平均存货
总资产周转率 = 营业收入 / 平均总资产

净资产收益率（ROE）= 销售净利率 × 总资产周转率 × 权益乘数
（杜邦分析体系）
```

### 3.2 投资决策类公式

```
NPV = ∑(NCFt / (1+r)^t) - I0
IRR：使NPV=0的r值
PI（盈利指数）= 未来现金流入现值 / 初始投资
投资回收期 = 累计净现金流量首次为正的年份 - 1 + （上年累计净现金流量绝对值 / 当年净现金流量）
```

### 3.3 融资决策类公式

```
EPS（无差别点分析）：
(EBIT - I1) × (1 - T) / N1 = (EBIT - I2) × (1 - T) / N2

资本成本：
债务成本 Kd = 利率 × (1 - T)
优先股成本 Kp = Dp / Pp
普通股成本 Ke = D1/P0 + g （股利增长模型）
```

### 3.4 成本管理类公式

```
完全成本法下：
单位产品成本 = 直接材料 + 直接人工 + 变动制造费用 + 固定制造费用分摊

变动成本法下：
单位产品成本 = 直接材料 + 直接人工 + 变动制造费用

标准成本差异分析：
价格差异 =（实际价格 - 标准价格）× 实际用量
数量差异 =（实际用量 - 标准用量）× 标准价格
```

### 3.5 并购估值类公式

```
企业价值 EV = 市值 + 带息负债 - 现金及等价物
EV/EBITDA 倍数估值 = 可比企业平均 EV/EBITDA × 目标企业 EBITDA
市盈率估值 = 可比企业平均市盈率 × 目标企业净利润
市净率估值 = 可比企业平均市净率 × 目标企业净资产
```

## 五、答题技巧与万能模板

### 5.1 案例分析题答题步骤

1. **读题**：先读题目要求，明确回答几个问题
2. **找关键点**：在题目中标记关键数据、关键条件
3. **选公式**：根据问题选择对应公式
4. **列计算**：写出计算公式 → 代入数据 → 得出结果
5. **写分析**：计算结果 + 文字分析（结论 + 理由）

### 5.2 计算分析题万能答题格式

```
【计算过程】
1. 公式：XXX = ......
2. 代入：XXX = ......
3. 结果：XXX = ......

【分析结论】
根据计算结果，......（给出结论），原因是......（结合案例分析）
```

### 5.3 文字分析题答题要点

- **先给结论，再给理由**
- **分条作答，条理清晰**
- **结合案例，不要只写理论**
- **关键词要准确**（如"经营杠杆""财务杠杆"不能混用）

### 5.4 内控缺陷答题模板

```
（1）是否存在缺陷：存在/不存在

（2）缺陷类型：重大缺陷/重要缺陷/一般缺陷

（3）理由：......（引用COSO框架或内控规范）

（4）整改建议：......
```

### 5.5 财务战略选择答题模板

```
（1）当前财务状况分析：......（结合财务指标）

（2）战略环境分析：
- 外部机会：......
- 外部威胁：......
- 内部优势：......
- 内部劣势：......

（3）财务战略选择：......（扩张型/稳健型/防御型）

（4）理由：......
```

## 七、高频考点速记

### 7.1 必须记住的公式

1. **NPV公式**：`NPV = ∑(NCFt/(1+r)^t) - I0`
2. **ROE杜邦分解**：`ROE = 销售净利率 × 总资产周转率 × 权益乘数`
3. **EVA公式**：`EVA = 税后净营业利润 - 资本占用 × WACC`
4. **保本点**：`保本销售量 = 固定成本/(单价-单位变动成本)`
5. **DOL/DFL/DTL**：`DTL = DOL × DFL`

### 7.2 必须记住的概念

- **COSO内控五要素**：控制环境、风险评估、控制活动、信息与沟通、监控
- **平衡计分卡四维度**：财务、客户、内部流程、学习与成长
- **并购协同效应**：经营协同、财务协同、管理协同
- **资本结构理论**：MM理论、权衡理论、优序融资理论

### 7.3 必考章节（重点复习）

1. **第四章**：投融资决策（计算量大，必考）
2. **第五章**：成本管理（本量利分析年年考）
3. **第七章**：绩效评价（EVA计算高频）
4. **第三章**：内控与风险管理（文字分析题重点）

## 九、常见计算失误防范

1. **折现率用错**：注意题目中是税前还是税后的利率
2. **年金终值/现值混淆**：看清是期初还是期末支付
3. **β系数处理**：注意是否为卸载/加回财务杠杆
4. **所得税处理**：注意是否考虑所得税影响
5. **单位统一**：确保万元、亿元单位统一
