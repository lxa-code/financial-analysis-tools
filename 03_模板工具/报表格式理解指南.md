## 一、格式总览速查表

### 1.1 字体体系

| 层级 | 字体 | 字号 | 加粗 | 颜色 | 行距 | 用途 |
|------|------|------|------|------|------|------|
| 封面主标题 | 方正小标宋简体 | 22pt（二号） | ❌ | 黑 | 30磅 | 月度财务情况说明封面 |
| 一级标题 | 方正小标宋简体 | 22pt（二号） | ❌ | 黑 | 30磅 | "一、关键指标完成情况" |
| 二级标题 | 黑体 | 16pt（三号） | ❌ | 黑 | 30磅 | "（一）整体情况" |
| 三级标题 | 楷体_GB2312 | 16pt（三号） | ❌ | 黑 | 30磅 | "1. 利润总额情况" |
| 正文 | 仿宋_GB2312 | 16pt（三号） | ❌ | 黑 | 30磅 | 所有正文段落 |
| 正文表头 | 黑体 | 12pt（小四） | ✅ | 黑 | — | 表格列标题 |
| 表格数据 | 仿宋_GB2312 | 11pt | ❌ | 黑 | — | 表格数据行 |

> ⚠️ **注意两个模板体系**：
> - `生成Word简报模板.py`：一级标题**黑体16pt**，二级标题**楷体16pt**（经营财务月报）  
> - `生成文字模板.py`：一级标题**方正小标宋22pt**，二级标题**黑体16pt**（月度财务情况说明）  
> - 请根据目标文档类型选用对应的标准

### 1.2 段落格式

| 属性 | 值 | 说明 |
|------|-----|------|
| 行间距 | 固定值 30pt | 所有段落统一 |
| 段前间距 | 0pt | 无额外段前空 |
| 段后间距 | 0pt | 无额外段后空 |
| 首行缩进 | 2字符 | 正文段落缩进 |
| 对齐方式 | 两端对齐（默认） | 封面居中，签名右对齐 |
| 字体颜色 | RGB(0,0,0) 黑色 | 全文档统一黑色 |

### 1.3 页面设置

| 属性 | 值 |
|------|-----|
| 左边距 | 2.8cm |
| 右边距 | 2.6cm |
| 上边距 | 3.7cm |
| 下边距 | 3.5cm |
| 纸张大小 | A4（210mm × 297mm） |

### 1.4 表格样式

| 位置 | 字体 | 字号 | 底色 | 字体颜色 | 行高 |
|------|------|------|------|----------|------|
| 表头 | 黑体 | 10pt（或12pt） | #1F4E79 深蓝 | 白色 (#FFFFFF) | 最小值 |
| 数据行 | 宋体 | 10pt | 无底色 | 黑色 | 最小值 |
| 表格边框 | — | — | — | — | `Table Grid` 样式 |

## 二、两大文档类型对比

### 2.1 经营财务月报（`生成Word简报模板.py`）

**文档结构**（6章体系）：

```
封面
├─ 标题：城发投经营财务月报（方正小标宋 32pt，蓝色，加粗）
├─ 期数：2026年X月（微软雅黑 24pt）
├─ 编制单位：综合管理部
└─ 编制日期

目录（6章）

一、本月经营概览
├─ （一）核心指标完成情况 → 表格
├─ （二）板块利润贡献分析 → 饼图
├─ （三）本月亮点 → 编号列表
└─ （四）本月关注 → 编号列表

二、PPP项目板块
├─ （一）核心指标 → 表格
├─ （二）项目状态分析 → 项目数 + 饼图
└─ （三）效益排行 → Top5 列表

三、供热项目板块
├─ （一）核心指标 → 表格
├─ （二）区域分布 → 热力图
└─ （三）成本分析 → 比例 + 饼图

四、平台公司板块
├─ （一）核心指标 → 表格
└─ （二）效益排行 → Top3 列表

五、本部板块
├─ （一）核心指标 → 表格
└─ （二）费用控制分析 → 比例 + 饼图

六、风险预警与建议
├─ （一）风险预警 → 表格（风险点/等级/描述/措施/责任/时限）
└─ （二）下月重点工作建议 → 编号列表

签名栏：编制人 / 审核人 / 批准人
```

**标题层级**：一级=黑体16pt，二级=楷体16pt

**封面特殊**：标题蓝色(RGB 0,82,204)、32pt、加粗，期数微软雅黑 24pt

### 2.2 月度财务情况说明（`生成文字模板.py`）

**文档结构**（6章体系）：

```
封面
├─ 保密标识：重要资料 注意保密（黑体 16pt 粗体）
├─ 标题：城发投资{{YYYY}}年度{{MM}}月份月度财务情况说明（方正小标宋 22pt）
└─ 日期：二零二六年{{MM}}月（仿宋_GB2312 16pt）

目录（6章）

一、关键指标完成情况
├─ （一）整体情况 → 文字 + 表格（利润总额/管理费/回款）
└─ （二）本部情况 → 文字 + 表格（利润总额/管理费/资金）

二、盈利情况
├─ （一）整体盈利情况 → 文字 + 表格
├─ （二）本部盈利情况 → 文字
└─ （三）下属企业盈利情况 → 表格

三、资产负债情况
├─ （一）整体情况 → 文字 + 表格
└─ （二）本部情况 → 文字

四、资金情况
├─ （一）整体情况 → 文字
├─ （二）本部情况 → 文字
└─ （三）归集情况 → 文字 + 表格

五、投资情况
├─ （一）股权投资情况 → 文字
└─ （二）债权投资情况 → 文字

六、预算情况
├─ （一）预算执行情况 → 文字 + 表格
└─ （二）预算计划情况 → 文字
```

**标题层级**：一级=方正小标宋22pt，二级=黑体16pt，三级=仿宋16pt

**关键区别**：
- 月度财务情况说明的一级标题使用 **方正小标宋简体22pt**（更正式）
- 经营财务月报的一级标题使用 **黑体16pt**（更紧凑）

## 三、python-docx 实现参考

### 3.1 标题样式设置（核心函数）

```python
from docx import Document
from docx.shared import Pt, RGBColor
from docx.oxml.ns import qn

def set_heading_style(heading, level):
    """两套标题体系"""
    
    # ===== 体系A：月度财务情况说明（一级=方正小标宋） =====
    if level == 1:  # 一级标题：方正小标宋简体 22pt
        for run in heading.runs:
            run.font.name = '方正小标宋简体'
            run.font.size = Pt(22)
            run.font.bold = False
            run.font.color.rgb = RGBColor(0, 0, 0)
            run._element.rPr.rFonts.set(qn('w:eastAsia'), '方正小标宋简体')
    
    elif level == 2:  # 二级标题：黑体 16pt
        for run in heading.runs:
            run.font.name = '黑体'
            run.font.size = Pt(16)
            run.font.bold = False
            run.font.color.rgb = RGBColor(0, 0, 0)
            run._element.rPr.rFonts.set(qn('w:eastAsia'), '黑体')
    
    elif level == 3:  # 三级标题：楷体_GB2312 16pt
        for run in heading.runs:
            run.font.name = '楷体_GB2312'
            run.font.size = Pt(16)
            run.font.bold = False
            run.font.color.rgb = RGBColor(0, 0, 0)
            run._element.rPr.rFonts.set(qn('w:eastAsia'), '楷体_GB2312')
    
    # ===== 体系B：经营财务月报（一级=黑体） =====
    # 如需使用月报体系，交换 level 1 和 level 2 的字体设定

def set_body_style(para, indent=True):
    """正文样式：仿宋_GB2312 16pt，行距30磅固定值"""
    for run in para.runs:
        run.font.name = '仿宋_GB2312'
        run.font.size = Pt(16)
        run.font.bold = False
        run.font.color.rgb = RGBColor(0, 0, 0)
        run._element.rPr.rFonts.set(qn('w:eastAsia'), '仿宋_GB2312')
    
    pf = para.paragraph_format
    pf.line_spacing_rule = 2     # WD_LINE_SPACING.EXACTLY（固定值）
    pf.line_spacing = Pt(30)
    pf.space_before = Pt(0)
    pf.space_after = Pt(0)
    if indent:
        pf.first_line_indent = Pt(32)  # 约2字符（16pt × 2）
```

### 3.3 表格设置

```python
from docx.shared import Pt, RGBColor
from docx.oxml.ns import qn, nsdecls
from docx.oxml import parse_xml

def style_table(table):
    """设置表格为标准样式"""
    table.style = 'Table Grid'
    
    # 表头行样式：深蓝底 + 白色加粗
    for cell in table.rows[0].cells:
        # 设置单元格底色 #1F4E79
        shading = parse_xml(f'<w:shd {nsdecls("w")} w:fill="1F4E79"/>')
        cell._tc.get_or_add_tcPr().append(shading)
        
        for p in cell.paragraphs:
            for run in p.runs:
                run.font.name = '黑体'
                run.font.size = Pt(10)
                run.font.bold = True
                run.font.color.rgb = RGBColor(255, 255, 255)  # 白色
                run._element.rPr.rFonts.set(qn('w:eastAsia'), '黑体')
    
    # 数据行样式：宋体 10pt
    for row in table.rows[1:]:
        for cell in row.cells:
            for p in cell.paragraphs:
                for run in p.runs:
                    run.font.name = '宋体'
                    run.font.size = Pt(10)
                    run.font.bold = False
                    run.font.color.rgb = RGBColor(0, 0, 0)
                    run._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')
```

### 3.4 占位符替换模式

```python
# 月度财务情况说明使用 {{}} 双花括号占位符
PLACEHOLDERS = {
    '{{YYYY}}': '2026',
    '{{MM}}': '04',
    '{{利润总额_整体}}': '5,120.87',
    '{{利润总额_整体_同比}}': '-32.88',
    # ... 更多占位符
}

def fill_placeholders(doc, data: dict):
    """遍历段落、表格，替换所有占位符"""
    for para in doc.paragraphs:
        for run in para.runs:
            for key, val in data.items():
                if key in run.text:
                    run.text = run.text.replace(key, str(val))
    for table in doc.tables:
        for row in table.rows:
            for cell in row.cells:
                for para in cell.paragraphs:
                    for run in para.runs:
                        for key, val in data.items():
                            if key in run.text:
                                run.text = run.text.replace(key, str(val))
```

## 四、文档生成工作流

### 4.1 从零生成月报

```
① 确定文档类型 ───→ 月度财务情况说明？经营月报？
         │
② 选择标题体系 ───→ 方正小标宋体系 / 黑体体系
         │
③ 创建 Document ───→ 设置页面、默认字体
         │
④ 逐章写入 ────────→ heading → body → table → 分页
         │
⑤ 表格格式化 ──────→ 表头深蓝白字、数据行宋体10pt
         │
⑥ 保存输出 ────────→ .docx 文件
```

### 4.2 模板填充工作流

```
① 加载模板 .docx ──→ Document('模板.docx')
         │
② 加载数据源 ──────→ Excel / JSON / 内存dict
         │
③ 占位符替换 ──────→ 遍历 paragraphs + tables 中的 {{key}}
         │
④ 数据查漏 ────────→ 检查是否有未填充的占位符
         │
⑤ 保存输出 ────────→ 另存为新文件（保留模板）
```

## 五、常见错误与纠正

| 错误 | 原因 | 正确做法 |
|------|------|----------|
| 正文不见了首行缩进 | 忘记设置 `first_line_indent` | `pf.first_line_indent = Pt(32)` |
| 中文字体无效 | 未设置 `w:eastAsia` | `run._element.rPr.rFonts.set(qn('w:eastAsia'), '字体名')` |
| 行距看起来不对 | 用了 MULTIPLE 而非 EXACTLY | `pf.line_spacing_rule = 2` → 固定值 |
| 表头蓝色过浅 | 颜色码错误 | 使用 `#1F4E79`（非其他蓝色） |
| 标题加粗了 | 未显式设置 bold=False | 每个 run 必须 `run.font.bold = False` |
| 封面字体用错 | 混淆了两套体系 | 参照 §2 对比表选择 |
| 表格边框丢失 | 未设置 table.style | `table.style = 'Table Grid'` |
| 段落间距不一致 | 段前段后未归零 | 必须显式设置 `Pt(0)` |

## 六、字体备选方案

部分系统可能没有 `仿宋_GB2312` 或 `方正小标宋简体`，按优先级降级：

| 目标字体 | 备选1 | 备选2 | 备选3 |
|----------|-------|-------|-------|
| 仿宋_GB2312 | 仿宋 | Fangsong | 宋体 |
| 方正小标宋简体 | 华文中宋 | 宋体 | — |
| 楷体_GB2312 | 楷体 | KaiTi | 仿宋_GB2312 |
| 黑体 | SimHei | 微软雅黑 | — |

```python
# 字体安全设置辅助函数
def safe_font(run, preferred, fallbacks):
    """尝试设置首选字体，不可用时降级"""
    run.font.name = preferred
    run._element.rPr.rFonts.set(qn('w:eastAsia'), preferred)
    # Word 会自动降级处理，rFonts 中的字体以列表形式保存
```

## 七、快速参考代码块

### 完整的一级标题 + 正文段落示例

```python
from docx import Document
from docx.shared import Pt, RGBColor, Cm
from docx.oxml.ns import qn

doc = Document()

# 页面设置
sec = doc.sections[0]
sec.left_margin = Cm(2.8)
sec.right_margin = Cm(2.6)
sec.top_margin = Cm(3.7)
sec.bottom_margin = Cm(3.5)

# 一级标题
h1 = doc.add_heading('一、关键指标完成情况', level=1)
for r in h1.runs:
    r.font.name = '方正小标宋简体'; r.font.size = Pt(22)
    r.font.bold = False; r.font.color.rgb = RGBColor(0,0,0)
    r._element.rPr.rFonts.set(qn('w:eastAsia'), '方正小标宋简体')

# 二级标题
h2 = doc.add_heading('（一）整体情况', level=2)
for r in h2.runs:
    r.font.name = '黑体'; r.font.size = Pt(16)
    r.font.bold = False; r.font.color.rgb = RGBColor(0,0,0)
    r._element.rPr.rFonts.set(qn('w:eastAsia'), '黑体')

# 正文段落
p = doc.add_paragraph(
    '截至2026年4月，城发投资板块合并报表利润总额5,120.87万元……')
for r in p.runs:
    r.font.name = '仿宋_GB2312'; r.font.size = Pt(16)
    r.font.bold = False; r.font.color.rgb = RGBColor(0,0,0)
    r._element.rPr.rFonts.set(qn('w:eastAsia'), '仿宋_GB2312')
pf = p.paragraph_format
pf.line_spacing_rule = 2
pf.line_spacing = Pt(30)
pf.space_before = Pt(0)
pf.space_after = Pt(0)
pf.first_line_indent = Pt(32)

doc.save('示例.docx')
```
